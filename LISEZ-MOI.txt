PHILO CLASS — VERSION CORRIGÉE
Cette version contient les données des cours directement dans index.html.
Sur Android :
1. Téléchargez le fichier HTML ou le ZIP.
2. Pour le ZIP : extrayez d'abord le dossier.
3. Ouvrez PHILO_CLASS/index.html avec Chrome.
4. Appuyez sur « Cours complets » : les 14 chapitres doivent apparaître.
Vous pouvez aussi ouvrir directement PHILO_CLASS_Terminale_A.html, sans extraction.
